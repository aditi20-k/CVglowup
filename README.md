# CVGlowUp ✨

AI-powered CV review and improvement agent.

CVGlowUp analyzes a CV, identifies areas for improvement, provides manager-style feedback, and generates an improved CV.

## Tech Stack

* Python
* Claude API
* FastAPI
* Streamlit
* Jinja2
* WeasyPrint
* Docker
* Kubernetes
* Jenkins
* Terraform
* Prometheus & Grafana
